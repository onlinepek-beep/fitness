# ЛФК — карта визуальных материалов

Основа приложения — врачебный комплекс из 31 упражнения. Текст назначения, нумерация, повторы и дыхательные указания не редактируются.

Книга И. Борщенко «Большая книга упражнений для спины» используется только как дополнительный источник визуальной механики. Совпадение не предполагается автоматически.

## Контроль качества иллюстраций

- Один и тот же взрослый мужчина, единый стиль съёмки и фон.
- На карточке показывать исходное положение и ключевую фазу движения; при необходимости — третью фазу возврата.
- Стрелки показывают только направление движения, не заменяют описание.
- Не добавлять текст назначения внутрь сгенерированного изображения: подписи рендерятся интерфейсом из исходных данных.
- Не рисовать анатомическую подсветку без подтверждённой структуры.
- Если механика в книге отличается, приоритет у назначения врача; расхождение явно отмечается.
- Упражнения 6, 8, 23 и 31 сохраняют исходные неоднозначные формулировки без самостоятельного исправления.
