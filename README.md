# ЛФК · Поясничный отдел

Мобильное PWA-приложение для сопровождения персонального комплекса из 31 упражнения по двум листам врачебного назначения.

## Что есть в приложении

- 31 карточка с исходным положением, понятным описанием и оригинальным текстом назначения.
- Поиск по названию и тексту, фильтрация по исходному положению.
- Светлая, тёмная и системная темы.
- Отметки выполнения, дневной прогресс и календарь истории.
- Экспорт и импорт локальной резервной копии JSON.
- Справочные сопоставления с книгой И. Борщенко: совпадение/частичное сходство/не найдено, с указанием страниц.
- Офлайн-режим через Service Worker.

## Источники и медицинские ограничения

**Основной источник:** два листа врачебного назначения. Текст, дыхательные указания, дозировка и последовательность не должны корректироваться приложением.

**Дополнительный источник:** И. Борщенко, «Большая книга упражнений для спины: комплекс „Умный позвоночник“», раздел «Поясничная позиционная гимнастика» и отдельно отмеченные справочные фрагменты. Сходство не означает идентичность техники и не даёт основания заменять назначение.

- №6, №8 и №23 содержат неоднозначности дыхательных фаз в оригинале. Они сохранены без самостоятельного исправления.
- №31 заблокировано в интерфейсе до уточнения противоречия «поворот / скручивание запрещено».
- Приложение не подтверждает безопасность упражнений, не заменяет обучение у специалиста и не является новым медицинским назначением.

## Публикация через GitHub Pages

Открой Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save.

## Установка на телефон

- **iPhone:** открой HTTPS-ссылку в Safari → Поделиться → На экран «Домой».
- **Android:** открой в Chrome → меню → Установить приложение.

## Хранение данных

Отметки и настройки сохраняются в локальном хранилище браузера на устройстве. Для переноса на другое устройство используй экспорт JSON. Удаление данных браузера может удалить историю, если не сохранена резервная копия.

## Дизайн-ориентиры

Для структуры HEP (home exercise program) использованы распространённые паттерны приложений для домашней реабилитации: короткие карточки назначений, дозировка, фиксация выполнения и обзор прогресса. Справочный ориентир — Physitrack / PhysiApp. В приложение не копируются их материалы или упражнения.
