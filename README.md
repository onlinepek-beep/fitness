# ЛФК · Поясничный отдел

Мобильное PWA-приложение для сопровождения персонального комплекса из 31 упражнения по двум листам врачебного назначения.

## Что есть в приложении

- Карточки с фото, исходным положением, дозировкой, свёрнутым оригиналом упражнения, понятным объяснением и работающими частями тела.
- Поиск по названию и тексту, фильтрация по исходному положению.
- Светлая, тёмная и системная темы; системная тема следует за настройкой устройства.
- Отметки выполнения, дневной прогресс и календарь истории с просмотром отметок за выбранную дату.
- Экспорт и импорт локальной резервной копии JSON.
- Простое объяснение, биомеханика и медицинская оценка всех 31 упражнений.
- Необязательный свёрнутый промпт для создания иллюстрации.
- Локальная замена фото и возврат к исходному файлу через настройки.
- Офлайн-режим через Service Worker.
- Каталог программ: сейчас ЛФК для поясничного отдела; новые направления добавляются отдельными наборами упражнений.

## Иллюстрации: текущее ограничение

Сжатые исходные фотографии упражнений находятся в `Foto/Spina/1.jpg` … `31.jpg` и показываются в карточках по номеру. В «Настройки → Администрирование иллюстраций» можно выбрать замену для упражнения. Замена хранится в IndexedDB на этом устройстве; исходное фото в проекте остаётся на месте. Кнопка «Вернуть исходную фотографию» удаляет только локальную замену. Локальные замены не синхронизируются между устройствами и не входят в JSON-копию; очистка данных сайта/браузера удалит их. Промпт для №1 недоступен, поскольку техника в листе не раскрыта; для №31 в него включены дополнительные ограничения. Для общей библиотеки замен потребуется подключить облачное хранилище и защищённую авторизацию; нельзя размещать GitHub-токен или ключ администратора в клиентском коде.

## Источники и медицинские ограничения

**Основной источник:** два листа врачебного назначения. Текст, дыхательные указания, дозировка и последовательность не должны корректироваться приложением.

**Дополнительный справочный источник:** И. Борщенко, «Большая книга упражнений для спины: комплекс „Умный позвоночник“» может учитываться при подготовке понятных объяснений. Он не заменяет назначение и не используется как доказательство эффективности конкретного упражнения.

- №6, №8 и №23 содержат неоднозначности дыхательных фаз в оригинале. Они сохранены без самостоятельного исправления.
- №31 заблокировано в интерфейсе до уточнения противоречия «поворот / скручивание запрещено».
- Биомеханический разбор — анатомическая интерпретация, а не доказательство клинического эффекта.
- Медицинские утверждения опираются на данные по ЛФК в целом; их нельзя переносить на отдельное упражнение как доказательство эффективности именно этого движения.
- Приложение не подтверждает индивидуальную безопасность упражнений, не заменяет обучение у специалиста и не является новым медицинским назначением.

## Публикация через GitHub Pages

Открой Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save.

## Установка на телефон

- **iPhone:** открой HTTPS-ссылку в Safari → Поделиться → На экран «Домой».
- **Android:** открой в Chrome → меню → Установить приложение.

## Хранение данных

Отметки и настройки сохраняются в локальном хранилище браузера на устройстве. Для переноса на другое устройство используй экспорт JSON. Удаление данных браузера может удалить историю, если не сохранена резервная копия.

## Дизайн-ориентиры

Для структуры HEP (home exercise program) использованы распространённые паттерны приложений для домашней реабилитации: короткие карточки назначений, дозировка, фиксация выполнения и обзор прогресса. Справочный ориентир — Physitrack / PhysiApp. В приложение не копируются их материалы или упражнения.
