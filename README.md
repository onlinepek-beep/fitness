# ЛФК · Поясничный отдел

Мобильное PWA-приложение для персонального комплекса из 31 упражнения. Отметки выполнения сохраняются локально в браузере. Есть история занятий, экспорт и импорт резервной копии JSON.

## Публикация через GitHub Pages
Открой Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save.

## Установка на телефон
- iPhone: открой HTTPS-ссылку в Safari → Поделиться → На экран «Домой».
- Android: открой в Chrome → меню → Установить приложение.

## Медицинские ограничения
№6, 8 и 23 содержат неоднозначности дыхательных фаз в исходном назначении. №31 заблокировано до уточнения противоречия «поворот / скручивание запрещено». Приложение не заменяет очное обучение технике и не является медицинским назначением.
